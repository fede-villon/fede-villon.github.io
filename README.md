# fede-villon.github.io

Mi portfolio: **[fede-villon.github.io](https://fede-villon.github.io)**

HTML, CSS y JavaScript sin dependencias, con la misma estética que mi [perfil de GitHub](https://github.com/fede-villon). Tiene una terminal interactiva (`help`, `proyectos`, `abrir turnero`, `contacto`…) y las demos de mis proyectos se abren dentro de la página:

- [Despensa](https://github.com/fede-villon/despensa): versión navegable generada desde la app real con `herramientas/exportar_despensa.py`.
- [Bandeja](https://github.com/fede-villon/bandeja): el panel de revisión con los comprobantes de ejemplo.
- [Turnero](https://github.com/fede-villon/turnero): la web de reservas y el panel del local.
